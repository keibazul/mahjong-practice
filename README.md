# 작사 도장 · 리치 마작 연습

내 실력에 맞춰 강도가 바뀌는 AI 셋과 대국하면서, 약한 부분을 대국 중에 연습하는 리치 마작 연습장이다. 설치 없이 브라우저에서 바로 돌아가는 정적 웹사이트다.

## 무엇을 하나

- **4인 리치 마작 대국**: 쯔모·타패·치·퐁·깡·리치·론·유국·후리텐·본장·공탁까지 진행한다. 동풍전 기본, 반장전 선택.
- **나를 배우는 AI**: 내가 버린 패마다 타패 모델을 학습하고, 그 모델을 바탕으로 상대 AI를 만든다. 내가 이기면 AI가 강해지고 지면 약해져서 늘 팽팽한 승부가 되도록 맞춘다.
- **대국 중 연습**: 사부(코치)가 기술별 숙련도를 보고 약한 기술을 더 자주 묻는다.

| 기술 | 대국 중에 일어나는 일 |
| --- | --- |
| 패효율 | 효율 문제가 되는 순간 "유효패를 세고 버려라"라고 묻고, 버린 뒤 유효패 장수로 채점 |
| 대기 읽기 | 텐파이가 되면 대기패를 전부 고르게 함 |
| 후리텐 | 화료 형태가 되면 후리텐이어도 론 버튼이 뜬다. 누르면 이유를 설명하고, 참으면 칭찬 |
| 역 판단 | 역이 없어도 화료 버튼이 뜬다. 날 수 있는지 스스로 판단 |
| 점수 계산 | 누가 화료하든 점수를 4지선다로 먼저 맞히게 함 |
| 수비 | 누군가 리치하면 내 타패의 위험도를 채점하고 더 안전한 패를 알려 줌 |

배패도 약점 쪽으로 살짝 기울인다. 예를 들어 패효율이 약하면 2468·3445 같은 복합형이 들어간 손을 더 자주 받는다.

## 기계학습 구조

모든 계산은 브라우저 안에서 하고, 기록은 그 기기의 `localStorage`에만 저장한다.

1. **타패 모방 모델** (`js/ml.js`): 버림패 후보마다 9개 특징(샹텐 유지, 유효패 수, 위험도, 접기, 역패 쌍, 도라, 고립 요구패, 손님풍, 쯔모기리)을 뽑고, 내가 실제로 버린 패를 다항 로지스틱 회귀로 온라인 학습한다.
2. **상대 AI** (`js/ai.js`): 가중치 = 내 모델 + δ × (강한 기준 − 내 모델). δ가 0이면 나를 닮은 AI, 1이면 강한 기준 정책이다.
3. **강도 조절**: 매 국 점수 이동과 매 판 순위로 δ를 움직인다.
4. **숙련도 추정**: 문제와 실전 판단 결과를 기술별 베타 분포로 누적한다. 최근 결과에 더 무게를 둔다.

검증 결과 (`test/` 참고):

- 정책 강도, 150판씩: 강한 기준 평균 2.35위 · 수비 없음 2.43위 · 허술한 정책 2.72위 · 샹텐만 보는 정책 3.14위
- 학습률 선택: 가상의 사람 데이터에서 처음 보는 판단의 예측 오차(NLL)가 기본값 1.847 → 학습 후 1.477 (정답 모델 1.445)
- 강도 조절: 허술한 가상의 사람에게는 δ가 0.25 → 0.00으로 내려가고, 강한 사람에게는 0.45로 올라감

## 실행

```bash
python3 -m http.server 8123
# 브라우저에서 http://localhost:8123 열기
```

GitHub Pages로 배포하면 저장소 주소 그대로 열 수 있다 (Settings → Pages → Branch: `main`, 폴더 `/`).

## 테스트

Node 18 이상.

```bash
npm test
```

- `test/yaku.test.js`: 역·부수·점수
- `test/sim.test.js`: AI끼리 자동 대국, 점수 보존
- `test/chaos.test.js`: 무작위 합법 행동으로 엔진 구석 경우
- `test/ml.test.js`: 모방 학습과 강도 조절

## 규칙

쿠이탄 있음, 아카도라 없음, 절상만관 없음, 역만끼리 겹치면 배수(국사 13면 같은 더블 역만은 없음). 아직 없는 것: 창깡, 구종구패 유국, 사풍연타·사깡유국, 유국만관, 리치 후 안깡.
